# Abstract Algebra — Interactive

An interactive abstract algebra course with Canvas 2D visualizations and KaTeX-rendered mathematics.

**Live site:** [https://hengzhe-science-classroom.github.io/HZ-abstract-algebra/](https://hengzhe-science-classroom.github.io/HZ-abstract-algebra/)

## Features

- KaTeX-rendered mathematics (display and inline)
- Interactive Canvas 2D visualizations with sliders and animation
- Exercises with hints and solutions
- Progress tracking via localStorage
- Zero external dependencies (only KaTeX CDN)

## Quick Start

```bash
# Clone and open
git clone https://github.com/Hengzhe-Science-Classroom/HZ-abstract-algebra.git
open index.html
```
